# Project: opz — deployment & security labs

_Last updated: 2026-10-25_

## Objective

Learn deployment and security by working through small, standalone labs instead of waiting
for a big project. Each lab shrinks a real incident to something that runs on a laptop in
under an hour: break it, diagnose it, fix it, prove the fix with a check that can fail, and
write a short retro.

## Current Phase

Track D runs on local emulators, not a paid account. Next: solve the built ones,
starting with 05 (OOMKilled) or 06 (webhook replay).
